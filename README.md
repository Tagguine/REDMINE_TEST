📘 REDMINE_TEST

This repository contains scripts and resources related to a test automation project in a ticket management environment.

🎯 Project Objective

The goal of this project is to practice test automation techniques to improve the validation and execution of functional scenarios within an application system.

📁 Repository Structure
Scripts/ – Automation test scripts and execution files
Ressources/ – Test data and configuration files required for execution
results/ – Generated test reports and execution results
.vscode/ – Development environment configuration
🛠️ Tools & Technologies
Robot Framework
Selenium WebDriver
Test automation scripts
Functional testing practices
📌 Author

Personal project developed as part of a learning experience in software test automation.
